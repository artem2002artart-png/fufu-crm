# Фугу CRM

Первая демонстрационная версия CRM для магазина детской одежды «Фугу».

## Что есть в v0.1
- Панель обзора с тестовыми показателями
- Разделы обращений, заказов, каталога и клиентов
- Черновик правил для ИИ-продавца
- Адаптивный интерфейс для телефона и компьютера

## Важно
Все записи и показатели сейчас демонстрационные. Реальные сообщения не подключены, ИИ не отправляет ответы, остатки и заказы не синхронизируются.

2. Подключить Supabase: база данных и авторизация.
3. Подключить Telegram-бота.
4. Подключить сообщения сообщества ВКонтакте.
5. Проверить доступные официальные API Авито и подключить при наличии нужного доступа.
6. Добавить журнал действий, согласование ответов и передачу сложных обращений менеджеру.

## Запуск
Открой `index.html` в браузере. Проект не требует сборки на текущем этапе.
