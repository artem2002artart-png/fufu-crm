# Фугу CRM

Первая версия интерфейса CRM для магазина детской одежды «Фугу».

## Уже реализовано
- Обзор с показателями и последними обращениями.
- Демонстрационные диалоги для ВКонтакте, Telegram и Авито.
- Заказы со сменой статусов.
- Клиентская база с поиском.
- Каталог товаров с добавлением карточек.
- Настройки будущего ИИ-продавца и база знаний магазина.
- Адаптивный интерфейс для компьютера и телефона.
- Сохранение тестовых данных в браузере.

## Запуск
Откройте `index.html` в браузере. Для публикации включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Важно
Сейчас это прототип интерфейса, а не подключённая CRM: диалоги демонстрационные, сообщения не отправляются, ИИ не отвечает клиентам. Данные хранятся в localStorage только в текущем браузере и не синхронизируются между устройствами.
